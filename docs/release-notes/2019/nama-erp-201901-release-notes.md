# Nama ERP Release Notes - January 2019

::: info Release Information
**Release Date:** January 2019  
**Release Number:** 201901
:::

## Additions

### Inventory
- **Inventory Count Voucher:** Added the option **"Start New Year Inventory Count with Updated Balances"** on the document header.
- **Item File:** Added the field **"New Year Storage Strategy"** with advanced options.
- Added the report **"New Year Inventory Plan"** based on prior-year data.
- **Stock Receipt Voucher:** Added the option **"Automatically Apply New Year Prices"**.
- Added the option **"Review Inventory Policies Annually"** in the distribution management settings.

### Sales
- **Sales Invoice:** Added the field **"New Year Sales Targets"** on the document header.
- **Quotations:** Added the offer **"New Year Welcome Offers"** to attract customers.
- **Sales Order:** Added the option **"Link Orders to the Annual Sales Plan"**.
- Added the report **"Growth Forecast for the New Year"** based on historical trends.
- **Sales Invoice:** Added the ability to apply updated New Year prices.

### Purchasing
- **Purchase Invoice:** Added the field **"Annual Purchasing Plan"** on the document header.
- **Purchase Order:** Added the option **"Review Vendor Agreements for the New Year"**.
- Added the report **"New Year Purchasing Needs Analysis"** by seasonality.
- **Purchase Invoice:** Added the ability to apply updated payment terms.

### Accounting
- **Receipt Voucher:** Added the option **"Apply New Collection Policies"** on the document header.
- **Payment Voucher:** Added the field **"New Year Expense Budget"** with tracking.
- Added the report **"New Year Financial Plan and Budget"** with forecasts.
- **Journal Voucher:** Added the ability to start an updated chart of accounts for the new year.

### Service Center
- **Job Order:** Added the field **"New Year Service Development Plan"**.
- Added the report **"New Year Customer Service Strategy"** with specific targets.
- **Job Order:** Added the ability to update maintenance contracts for the new year.
- Added the dashboard **"New Year Target Performance Indicators"**.

### Human Resources
- **Payroll Voucher:** Added the ability to apply annual raises for the new year.
- Added the field **"New Year Professional Development Goals"** to the employee file.
- **Leave Voucher:** Added the option **"Renew Leave Balance for the New Year"**.
- Added the report **"New Year HR and Recruitment Plan"**.

### Manufacturing
- **Production Order:** Added the field **"New Year Production Targets"** on the document header.
- **Production Execution Document:** Added the ability to apply updated quality standards.
- Added the report **"New Year Technical Development Plan"** for equipment and processes.
- **Production Order:** Added the ability to update production capacity plans.

### Banks
- **Letter of Guarantee:** Added the field **"Review Credit Limits for the New Year"**.
- Added the report **"New Year Banking and Credit Plan"** with forecasts.
- **Cheques:** Added the ability to start new chequebooks for the updated year.
- **Bank Reconciliation Memo:** Added the ability to start new year reconciliations.

### Point of Sale
- Added the ability to apply New Year prices across all points of sale.
- Added the option **"New Year Welcome Offers"** with a set duration.
- Added the ability to update loyalty programs and reward points.
- Added the report **"New Year Point of Sale Development Plan"**.

### Real Estate
- **Sales Contract:** Added the field **"Update Property Prices for the New Year"**.
- Added the report **"New Year Real Estate Investment Plan"** with forecasts.
- **Collect Document:** Added the ability to apply updated collection policies.

## Settings

- Added the option **"Fully Configure the System for the New Fiscal Year"** in Global Config.
- **Scheduled Task:** Added the ability to schedule operational start-of-year tasks.
- Added the **"New Year Data and Settings Migration"** system, automatically.
- Improved the backup system to support the start of the new year.
- Added the option **"Update All New Year Policies and Procedures"**.

## Fixes

### Inventory
- **Inventory Count Voucher:** Fixed an issue where, when starting the new year inventory count, some data from the previous year was not carried over.
- **Item File:** Fixed an issue where the storage strategy was not applied equally to all item categories.
- **Inventory Plan Report:** Fixed an issue where seasonal forecasts were not accurate enough.
- **Apply New Year Prices:** Fixed an issue where it did not work with items in different currencies.

### Sales
- **Sales Invoice:** Fixed an issue where New Year sales targets were not distributed across periods realistically.
- **New Year Offers:** Fixed an issue where they were not applied to customers with confirmed price contracts.
- **Link Orders to the Sales Plan:** Fixed an issue where it did not work with urgent or exceptional orders.
- **Growth Forecast Report:** Fixed an issue where it did not account for expected economic changes.

### Purchasing
- **Annual Purchasing Plan:** Fixed an issue where it was not fully integrated with production and sales plans.
- **Vendor Agreements Review:** Fixed an issue where it did not cover all sub-clauses and terms.
- **Purchasing Needs Report:** Fixed an issue where it did not account for expected price fluctuations.
- **Updated Payment Terms:** Fixed an issue where they were not applied to long-term contracts.

### Accounting
- **New Collection Policies:** Fixed an issue where they were not applied to overdue debts from the previous year.
- **Expense Budget:** Fixed an issue where tracking did not work with unexpected expenses.
- **Financial Plan Report:** Fixed an issue where forecasts did not account for expected inflation impact.
- **Updated Chart of Accounts:** Fixed an issue where some accounts did not carry over with correct balances.

### Service Center
- **Service Development Plan:** Fixed an issue where it did not account for expected technical developments in the field.
- **Customer Service Strategy:** Fixed an issue where the specified targets were not measurable in some cases.
- **Maintenance Contracts Update:** Fixed an issue where it did not include updates to spare part prices.
- **Target Performance Indicators:** Fixed an issue where they were not realistic compared to available capabilities.

### Human Resources
- **Apply Annual Raises:** Fixed an issue where it did not account for employee performance in the last quarter of the previous year.
- **Professional Development Goals:** Fixed an issue where they were not aligned with the company's strategic plans.
- **Renew Leave Balance:** Fixed an issue where it did not apply different policies by job type.
- **HR Plan:** Fixed an issue where it did not cover recruitment needs for new projects.

### Manufacturing
- **New Year Production Targets:** Fixed an issue where they did not account for current production capacity constraints.
- **Updated Quality Standards:** Fixed an issue where they were not applied equally across all production lines.
- **Technical Development Plan:** Fixed an issue where it did not include the expected costs of updates.
- **Production Capacity Plans Update:** Fixed an issue where it did not account for scheduled periodic maintenance dates.

### Banks
- **Credit Limits Review:** Fixed an issue where it did not include updated guarantees and insurance.
- **Banking Plan:** Fixed an issue where forecasts did not account for expected exchange rate fluctuations.
- **New Chequebooks:** Fixed an issue where they encountered problems connecting with banking systems.
- **New Year Reconciliations:** Fixed an issue where they did not start with the correct balances from the previous year.

### Point of Sale
- **Apply New Year Prices:** Fixed an issue where it did not work with items on special offers.
- **New Year Welcome Offers:** Fixed an issue where the specified duration was not applied correctly.
- **Loyalty Program Update:** Fixed an issue where it encountered problems carrying over customer points from the previous year.
- **Point of Sale Development Plan:** Fixed an issue where it did not cover expected operating costs.

### Real Estate
- **Property Prices Update:** Fixed an issue where it did not account for local market fluctuations.
- **Real Estate Investment Plan:** Fixed an issue where forecasts did not cover regulatory and legal risks.
- **Updated Collection Policies:** Fixed an issue where they were not applied to contracts with exceptional terms.

## General Improvements

- Improved system performance for handling new year data efficiently.
- Updated the user interface to reflect the new updates and developments.
- Added more planning and analysis tools for the new year.
- Improved the security system to protect data during the year transition.
- Developed helper tools to ensure a smooth transfer of data and operations.
