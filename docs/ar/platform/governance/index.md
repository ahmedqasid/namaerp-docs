# الرقابة والحوكمة

الضوابط التي تُبقي العمل المنجَز موثوقًا: اعتماد السجلات مستوى بعد مستوى، وإقفال الفترات المحاسبية وتجميد كل ما قبل تاريخ معيّن، والقواعد التي تمنع المستندات المخالفة أو تنبّه عليها، والحقول التي يجب ملؤها، وتاريخ النسخ الذي يبيّن من غيّر ماذا.
