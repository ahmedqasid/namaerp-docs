# Nama ERP Release Notes - May 2025

::: info Release Information
- **Release Date**: May 2025
- **Release Number**: Nama-ERP-202505
:::

## Additions

### Inventory

- A query field named (Ignore Quantity Tracking for Records Matching the Query) was added inside the Supply Chain term config settings.
- In the Item Relations grid, the "Free Item" relation was added.

### Real Estate

- Improved so that when a selected installment from a Property Purchase Contract's payments is paid, the installment amount must be considered by increasing the property value by that amount in the Property Revaluation voucher.

### Manufacturing

- A document named "Carton Material Issue" was added.

### Settings

- Improved so that when saving a report definition, the program verifies that the report language and the sub-reports' language are (language="groovy").

### Human Resources

- Saving was prevented when there are two overlapping departure permits on the same day for the same employee.

### Mobile Applications

- Attachments 1 and 2 were added to the Return to Work After Leave document in the Unified Application.
- In the Captain Order system, the ability to link the application within the branch to more than one machine in the same branch, instead of a single machine, was added.
