# الأتمتة والقواعد

دع النظام يؤدي عنك الأعمال المتكررة، وعرّف مرة واحدة الشروط التي يعيد بقية النظام استعمالها. تغطي المجموعة الأولى ما يعمل وحده — شاشة تستجيب لتغيّر حقل، ومهام وفق جدول زمني، ومستندات تتكرر. وتغطي الثانية وحدات البناء القابلة لإعادة الاستعمال: المعايير المحفوظة، والمعايير المكتوبة نصًّا، وقوائم الشاشات المسمّاة، والكيانات الافتراضية المبنية على SQL التي تقف خلف التقارير ولوحات المعلومات.
