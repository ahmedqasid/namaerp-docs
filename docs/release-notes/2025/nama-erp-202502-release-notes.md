# Nama ERP Release Notes - February 2025

::: info Release Information
- **Release Date**: February 2025
- **Release Number**: Nama-ERP-202502
- **File Type**: Monthly Release Notes
:::

## Additions

### Inventory

- Added the option "Show item selection window if the code does not exist" (items that start with the same code) to the supply chain settings.
- Added 5 extra Description fields to the QualityControlDoc document.

### Sales

- Added 5 Description fields to the Quotation document, matching their count on the Sales Order document, bringing their total to 20 Description fields.
- In the payment-details lines of the Sub-Item Sales Order screen (SISalesOrder), added the following field types, bringing each type's count to 3:
  - Reference 1 through Reference 3
  - Date 1 through Date 3
  - Checkbox 1 through Checkbox 3 (Boolean)
  - Number 1 through Number 3
  - Text 1 through Text 3
  - Attachment 1 through Attachment 3
- In the Sales Invoice, on the Payment Vouchers screen, added 2 (date - Boolean) fields to the lines.
- In the Offer Application Rules screen - Rule Type field, added the "Match All Lines" option.
- In Offers - the Free Items on Items grid, added the "applyOnItems = Apply on Items" field.
- In Bulk Messages, added attachments for the Header and the Details.

### Manufacturing

- Added a "Create Carton Material Planning Document" button to the Carton Sales Order screen.
- In the Carton Material Planning document, added the following fields to the Planning Items grid:
  - (Metric Length - Piece Count - Strike Count - Sheet Length - Sheet Width - Dimensions {Length - Width - Height} - swap the word "Value" for "Quantity" - Tongue - Trim - Reel Width - Run Width)
  - Note: Run Width = Piece Count × Sheet Width
  - Note: Trim = Reel Width − Run Width
  - The Box field, Classification 1 and Classification 2 in the Planning Materials grid
  - In the Carton Order grid, added the Customer, Quantity, Unit, Price and Net fields
  - Improved the Carton Specification file so that, in the Production Stage grid, once the Corrugation Type and Corrugation Factor are filled in, the (Corrugated) checkbox becomes mandatory
  - In the Planning Items grid, added a Number of Runs field and the total planned quantity for the order. If the order will run over more than one run, the system splits the runs across more than one line based on the calculation of the available quantities and the width available to it.
- Filtered the Purchase Coupons on the Sales Invoice by customer.
- Added a (Book and Term Config for Created Documents) group, generated by the "Create Carton Material Planning Document" button, to the Carton Sales Order term config.
- Added a numeric field named (Starch Content) to the Carton Type and Carton Specification files, used in the weight calculation formula.
- In the Carton Specification screen, the weight is now calculated automatically (Carton Weight = (Paper Gram Weight for all the paper + Starch Content) × Sheet Area).
- Added the Sales Representative field to the Carton Order document (Carton Sales Order).
- Divided the weight by 10000 in the Carton Specification screen to calculate the weight in kilograms.
- In the Manufacturing Template (Mold) file, added formula fields for the mold, to be used instead of the pattern formula in the Carton Specification when the mold type is (Forme) rather than Cylinder — and, when a mold formula exists, the sheet length and width for the specification are calculated from the mold's dimension formula.

### Fixed Assets

- Improved so that, after setting the selected from-period-to-period range (from fromPeriod to toPeriod) and clicking the Aggregate Assets button, the assets falling within that period are pulled in; then, when the voucher is saved, the system generates depreciation vouchers based on each asset's depreciation start date.
- Added tax settings to (Quotation - Price Request).

### Settings

- In "Tax Authority & Tax Policy Settings", added the following fields:
  - Tax 1 - Zero-Rate Sub-Code 1
  - Tax 1 - Zero-Rate Code 1
  - Tax 2 - Zero-Rate Sub-Code 2
  - Tax 2 - Zero-Rate Code 2
  - Tax 3 - Zero-Rate Sub-Code 3
  - Tax 3 - Zero-Rate Code 3
  - Tax 4 - Zero-Rate Sub-Code 4
  - Tax 4 - Zero-Rate Code 4
- Changed the "Export Current Record" option so it exports the record under the current document's code (the downloaded file is named, for example, ABC.xlsx), where ABC is the record's code.
- Created a new table that logs requests sent to Wathq (User - Commercial Registration Number - entity flow - the record - the incoming JSON data - the date).
- Added an option on the entity flow that allows sending more than one request to Wathq with the same registration number (by default, sending the same record more than once is blocked) — allowed only if true is entered for this input; when a matching line already exists in this table, the flow is blocked with a message giving the record's code and the date.
- Added a Function to do the following: (n6=countdistinct(details.text14
- Added a mechanism to run the GUU Post Action when a line is deleted.
- Added 10 Grids to the FormDoc documents, bringing the total to 20 grids instead of 10, for use in a large data-entry form for the customer.
- Added a new option in Global Config for system reports, "Allow Changing the Report from System to Non-System", disabled by default.
- Added the ability to use fields from within GenericReferences in extra filters.
- In the CourseEnrollment screen, added an ID Number field on the line; 5 reference fields and 5 description fields on the line, and also added 5 reference fields and 5 description fields to the screen.
- In Limit User To Year | LimitUserToYear, allowed leaving the Document Type and the type list empty so that it applies to the entire program.

### Point of Sale

- Added the following fields for display in Point of Sale, for use with tax-registered customers when sending to ZATCA (the Zakat, Tax and Customs Authority):
  - contactInfo.address.countryCode
  - contactInfo.address.city
  - contactInfo.address.area
  - contactInfo.address.buildingNumber
  - contactInfo.address.district
  - contactInfo.address.postalCode
  - contactInfo.address.landPlotNumber
- In the Point of Sale Delivery Service Costs file, added Customer and Customer Category to the lines, so a cost specific to a particular customer or customer category can be set.
- Added an option named "Add the Delivery Service Item When a Customer Is Selected" to Point of Sale Settings; when the option is selected, the Delivery Service item is added to the invoice once a customer is chosen.
- Added an option named "Do Not Add the Area Field Automatically" to the Point of Sale Interface Settings document, since the Area field otherwise appears automatically in Point of Sale when the Delivery Service item is used.
- Added an option named "Do Not Add the Driver Field Automatically" to the Point of Sale Interface Settings document, since the Driver field otherwise appears automatically in Point of Sale when the Delivery Service item is used.
- Created a permission named "Ability to Edit the Delivery Service Cost", which lets the cashier edit the delivery cost on the current invoice by opening a dialog via the (Alt+V) shortcut.
- Created a shortcut for the Item Code field so that it focuses the Code field (Ctrl+F).
- Created a mechanism so that pressing Alt + the shortcut opens the search dialog directly instead of focusing the Code field, and applied this mechanism to the Customer shortcut (F7), the Sales Representative shortcut (F8), and the Invoice Classification shortcut (Ctrl+Shift+I), as well as any field of the search-box type — with this mechanism continuing to work even if the user changes the default shortcuts via the Point of Sale Shortcuts document.

### Contracting

- Added the "Do Not Copy Details from Based On" option to the Analysis Card term config.
- In the Contracting Purchase Request screen, made the following improvements:
  - Added an Item field to the header, and a button for aggregating Analysis Item codes.
  - When a specific item is selected and the button is used, the system expands the lines of every Analysis Card and the Analysis Item codes that contain this item on the Analysis Card, with the quantity set to the item's remaining quantity (after subtracting the quantity previously requested).
- Added a Payments grid to the Contracting Purchase Request screen, similar to the Contracting Purchase Order screen.

### Human Resources

- In the Payroll Register, added the "Do Not Consider the Company When Grouping Employees" option.
- Added the following fields to the Loan Type document, in the Loan Terms lines:
  - Installment Maximum Type
  - Installment Maximum
- Added 5 text fields and 5 attachments to the Employee Status Change document.
- In the Loan Voucher, the employee is now filled in from the employee linked to the current user's file when creating a new record.
- Added 5 date fields and 5 description fields to the AggrRewardPenaltieLine line, in both the (Aggregate Reward - Penalty Voucher), and they are copied to the (Reward - Penalty Voucher).

### Project Management

- In the Task Execution Request document, made the following improvements:
  - Added 5 reference fields and 5 text fields
  - When the document is created and saved, it affects the tasks on its lines at the time recorded on the task.

### Customer Relationship Management (CRM)

- Added the "Add Spare Parts When Selecting the Task" field to the term config of the Service Request, Assay, and Add Tasks to Work Orders screens.

### Mobile Applications

- Added 'http authentication' to the Nama Al-Mujamma application.

### Reports

- In the report-creation tool, enabled searching by the "Record Creator" input.
- Added the "Include Drafts" option to the Printed Form creation tool.
